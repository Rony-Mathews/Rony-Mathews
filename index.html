Image Gallery

A personal mobile application for organizing and viewing images.

About the application

Image Gallery allows its administrator to upload original images, manage image metadata, review images, publish selected images and browse the resulting gallery.

The application uses a designated Google Drive folder to store and verify original image files. It uses a designated Google Sheet to maintain image metadata and publication status.

Published images may be optimized and stored using Cloudflare services so that they can be displayed in the gallery.

Use of Google data

Google Drive and Google Sheets data is accessed only to provide the image-management features requested by the account owner.

The use of information received from Google Workspace scopes will adhere to the Google API Services User Data Policy , including the Limited Use requirements.
